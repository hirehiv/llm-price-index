Notes
  • Only text-in/text-out models with a published input and output price and a context limit are included.
  • One row per provider+model: the same model can appear under several providers at different prices.
  • Responses are cached by GitHub Pages; Access-Control-Allow-Origin: * is set, so browser fetches work.
  • Field names are stable. Counts, prices and generated_at change on every rebuild.
  • Prices are published list rates. Providers change them; verify before committing volume.
  • Upstream: models.dev. This index is independent and takes no placement fees.
